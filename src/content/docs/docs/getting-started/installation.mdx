Voicebox 目前提供 macOS 与 Windows 安装包，Linux 构建尚未发布。首次生成时才会自动下载所选引擎的模型；应用启动时会拉起本地后端服务。

## 下载

| 平台 | 安装包 | 说明 |
| --- | --- | --- |
| macOS | `voicebox_aarch64.app.tar.gz` / `voicebox_x64.app.tar.gz` | Apple Silicon 与 Intel 分别打包 |
| Windows | `voicebox_x64_en-US.msi` / `voicebox_x64-setup.exe` | MSI 安装向导或 Setup 可执行文件 |
| Linux | 暂未提供 | 受 GitHub runner 磁盘空间限制，后续版本提供 |

### macOS

<Tabs>
  <TabItem label="Apple Silicon">
    下载 [voicebox_aarch64.app.tar.gz](https://github.com/jamiepine/voicebox/releases/latest/download/voicebox_aarch64.app.tar.gz)，解压后把应用移动到 Applications：

    ```bash title="终端"
    # 解压归档
    tar -xzf voicebox_aarch64.app.tar.gz

    # 移动到 Applications
    mv Voicebox.app /Applications/
    ```
  </TabItem>

  <TabItem label="Intel">
    下载 [voicebox_x64.app.tar.gz](https://github.com/jamiepine/voicebox/releases/latest/download/voicebox_x64.app.tar.gz)，步骤与 Apple Silicon 相同：

    ```bash title="终端"
    # 解压归档
    tar -xzf voicebox_x64.app.tar.gz

    # 移动到 Applications
    mv Voicebox.app /Applications/
    ```
  </TabItem>
</Tabs>

### Windows

<Tabs>
  <TabItem label="MSI 安装器">
    下载 [voicebox_x64_en-US.msi](https://github.com/jamiepine/voicebox/releases/latest/download/voicebox_x64_en-US.msi)，双击后按安装向导完成。
  </TabItem>

  <TabItem label="Setup 可执行文件">
    下载 [voicebox_x64-setup.exe](https://github.com/jamiepine/voicebox/releases/latest/download/voicebox_x64-setup.exe)，运行后按安装向导完成。
  </TabItem>
</Tabs>

### Linux

<Aside type="note">
  Linux 构建仍在准备中，目前受 GitHub runner 磁盘空间限制而无法产出。在 Linux 上可以先改用 [Docker 部署](/docs/getting-started/docker)，或者直接运行后端源码。
</Aside>

## 首次启动

第一次打开 Voicebox 时会依次发生三件事：

1. **模型下载**：第一个使用的 TTS 引擎会自动下载自身模型，体积从约 350 MB（Kokoro）到约 8 GB（TADA 3B）不等。多数人从 Qwen 1.7B（约 3.5 GB）起步。
2. **数据目录**：声音配置文件与生成的音频存放在下列位置。
   - macOS：`~/Library/Application Support/sh.voicebox.app/`
   - Windows：`%APPDATA%/sh.voicebox.app/`
   - Linux：`~/.config/sh.voicebox.app/`
3. **后端服务**：随应用打包的 Python 服务会自动启动，不需要单独运行。

<Aside type="note" title="首次生成会慢一些">
  首次生成需要等待模型下载完成，耗时明显长于之后。模型会缓存在本地，后续生成直接复用。
</Aside>

## 系统要求

### 最低配置

| 项目 | 要求 |
| --- | --- |
| 操作系统 | macOS 11+、Windows 10+ 或 Linux |
| 内存 | 8 GB |
| 存储 | 20 GB 以上（模型与数据；单个 TADA 3B 模型就约 8 GB） |
| CPU | 现代多核处理器 |

### 推荐配置

| 项目 | 要求 |
| --- | --- |
| 内存 | 16 GB 以上 |
| GPU | 支持 CUDA 的 NVIDIA 显卡（生成更快） |
| 存储 | 10 GB 以上可用空间 |

<Aside type="note">
  Voicebox 支持纯 CPU 推理，但速度远低于 GPU。需要接近实时的体验时，建议使用支持 CUDA 的显卡。
</Aside>

## 验证安装

<Steps>
  <Step title="启动应用">
    打开 Voicebox。
  </Step>
  <Step title="查看服务状态">
    左下角的状态指示灯应为绿色，表示本地后端已连通。
  </Step>
  <Step title="创建测试配置文件">
    进入 **Profiles**，新建一个声音配置文件。
  </Step>
  <Step title="生成一小段音频">
    生成一句短文本，确认 TTS 引擎可用。
  </Step>
</Steps>

<Aside type="tip">
  状态灯为绿色且能生成音频，说明安装已经就绪。若状态灯为红色，参见[故障排查](/docs/getting-started/troubleshooting)。
</Aside>
