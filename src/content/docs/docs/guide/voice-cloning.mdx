Voicebox 可以用一段很短的音频样本复刻某个人的声音，也就是**零样本声音克隆**。你提供 10–30 秒清晰语音，模型从中提取声音嵌入，之后就可以用这个声音生成任意文本。

## 支持克隆的引擎

目前有五个引擎支持克隆：

| 引擎 | 语言数 | 特点 |
| --- | --- | --- |
| **Qwen3-TTS**（0.6B / 1.7B） | 10 | 高质量多语言；表达指令与音色可在同一个参数里传入 |
| **Chatterbox Multilingual** | 23 | 语言覆盖最广——阿拉伯语、印地语、斯瓦希里语、希伯来语等 |
| **Chatterbox Turbo** | 英语 | 350M 快速模型，支持副语言情绪标签（`[laugh]`、`[sigh]`） |
| **LuxTTS** | 英语 | 轻量（约 1 GB 显存），48 kHz 输出，CPU 上 150 倍实时 |
| **TADA**（3B） | 10 | 语音语言模型，可连续生成 700 秒以上的长音频 |
| **TADA**（1B） | 英语 | 轻量版本，仅支持英语 |

<Aside type="tip">
不想录音频？直接用 Kokoro 或 Qwen CustomVoice 里打磨好的音色即可，见[预设音色](/docs/guide/preset-voices)。
</Aside>

## 工作原理

<Steps>
  <Step title="上传或录制样本">
    提供目标声音 10–30 秒的清晰语音。
  </Step>
  <Step title="引擎分析">
    选定的引擎分析音色特征、音调和说话习惯。
  </Step>
  <Step title="生成声音配置文件">
    生成声音嵌入，并随配置文件一起保存。
  </Step>
  <Step title="生成语音">
    用这个配置文件把任意文本生成成克隆音色。
  </Step>
</Steps>

## 为克隆选择引擎

不同引擎适合不同场景。配置文件网格会把不支持的引擎置灰，切换起来很直接。

| 你的目标 | 选择 |
| --- | --- |
| 在少数常见语言上要最好的整体质量 | **Qwen3-TTS 1.7B** |
| 更快的生成，质量略降 | **Qwen3-TTS 0.6B** |
| 需要 Qwen 那 10 种之外的语言（阿拉伯语、印地语等） | **Chatterbox Multilingual** |
| 带 `[laugh]` `[sigh]` 标签的富有表现力的英语 | **Chatterbox Turbo** |
| 只有 CPU 或显卡很弱、只要英语 | **LuxTTS** |
| 长文本生成（有声书、整章） | **TADA 3B** |

## 最佳实践

### 样本质量

| 该做 | 不该做 |
| --- | --- |
| 用 10–30 秒的音频 | 极短片段（不足 5 秒） |
| 清晰、稳定的说话 | 很重的背景噪声 |
| 背景噪声尽量少 | 音乐或多人声音叠加 |
| 自然的说话语速 | 过度处理过的音频 |

### 多个样本

加入同一说话人的多段样本能提升质量：

- 不同说话风格（随意、正式）
- 不同情绪（愉快、严肃）
- 不同录音条件

<Aside type="note">
样本越多样，模型学到的声音表示越稳健。对很有辨识度的声音尤其有用——否则模型容易把特点磨平。
</Aside>

## 各引擎支持的语言

- **Qwen3-TTS** — 英语、中文、日语、韩语、德语、法语、俄语、葡萄牙语、西班牙语、意大利语（10）
- **Chatterbox Multilingual** — 阿拉伯语、中文、丹麦语、荷兰语、英语、芬兰语、法语、德语、希腊语、希伯来语、印地语、意大利语、日语、韩语、马来语、挪威语、波兰语、葡萄牙语、俄语、西班牙语、斯瓦希里语、瑞典语、土耳其语（23）
- **Chatterbox Turbo** — 英语
- **LuxTTS** — 英语
- **TADA 3B** — 10 种语言；**TADA 1B** — 英语

完整的语言对照表与各引擎的细节说明见 [TTS 引擎开发者指南](/docs/developer/tts-engines)。

## 使用限制

<Aside type="danger">
克隆他人声音必须获得同意。确认你有权克隆该声音，并遵守当地关于合成语音内容的法律与项目 [SECURITY.md](https://github.com/jamiepine/voicebox/blob/main/SECURITY.md)。
</Aside>

- 效果取决于样本清晰度——噪声大的样本只会克隆出噪声
- 样本内部语气一致时效果最好
- 极端口音或言语障碍可能处理不好
- 背景噪声会降低质量，还可能引入伪影
