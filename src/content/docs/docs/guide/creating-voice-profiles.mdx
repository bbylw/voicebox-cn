声音配置文件（voice profile）是保存在本地的一个声音，可以在生成、故事和 API 中反复使用。配置文件分为两种，对应两条获取声音的路径：克隆型与预设型。

## 两种配置文件类型

| 类型 | 保存的内容 | 适用场景 |
| --- | --- | --- |
| **克隆型** | 一段或多段参考音频样本 + 声音嵌入 | 想复刻某个特定人的声音 |
| **预设型** | 指向某个引擎中预设音色的引用 | 想要打磨好、开箱即用的音色，不用准备音频 |

两种类型都在同一个 `Profiles` 标签页里，生成时的行为也一致。按目标选类型，再跟着下面对应的工作流走。

<Aside type="note">
还不确定选哪种？克隆能得到**特定**的声音，但需要干净的音频；预设音色立刻就有好声音，但你无法决定它听起来像谁。
</Aside>

## 工作流 A：克隆型配置文件

要从一段录音复刻某个人的声音时用这条流程。

<Steps>
  <Step title="准备音频">
    准备 10–30 秒清晰、背景噪声尽量少的语音。各引擎的差异见[声音克隆](/docs/guide/voice-cloning)。
  </Step>
  <Step title="新建配置文件">
    `Profiles` → `+ New Profile` → 选择一个克隆引擎（Qwen3-TTS、Chatterbox Multilingual、Chatterbox Turbo、LuxTTS 或 TADA）。
  </Step>
  <Step title="上传或录制样本">
    拖入一个音频文件，或用应用内的录音器直接录制。
  </Step>
  <Step title="生成测试">
    用这个配置文件生成一句话测试效果。质量不理想就补充更多样本。
  </Step>
</Steps>

### 音频要求（仅克隆）

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 时长 | 10–30 秒 | 太短质量差，太长没有必要 |
| 清晰度 | 清晰语音 | 无背景噪声，无音乐或其他人声叠加 |
| 音质 | 高保真 | 44.1 kHz 或 48 kHz 采样率，压缩尽量少 |
| 内容 | 自然语音 | 口语化的语气，完整的句子 |

### 文件格式

- **WAV**（推荐）— 无损
- **MP3** — 可用，压缩程度要低
- **M4A** — 可用
- **FLAC** — 无损替代格式

<Aside type="tip">
用 WAV 效果最好。避免使用压缩很重的格式。
</Aside>

### 录音要点

| 方面 | 要点 |
| --- | --- |
| 环境 | 安静的房间；关掉风扇、空调和家电；关窗减少室外噪声；用软装减少回声 |
| 麦克风摆位 | 距嘴 6–12 英寸；略微偏轴以减少喷麦（p、b、t）；有防喷罩就用；全程保持距离一致 |
| 录音设置 | 44.1 kHz 或 48 kHz 采样率；16 位或 24 位位深；单声道即可（立体声会被转换）；关闭自动增益控制 |

### 说话方式

- **自然语速** — 不要赶，也不要过慢
- **吐字清楚** — 每个字都发出来
- **音量稳定** — 保持一致的响度
- **正常语气** — 照平时的说法讲
- **完整句子** — 避免碎片和「嗯、啊」

### 多个样本

同一说话人加入多段样本通常能明显提升质量：

| 收益 | 说明 |
| --- | --- |
| 稳健性 | 模型能学到更完整的声音表示 |
| 泛化 | 更好地覆盖不同的说话风格 |
| 质量 | 减少伪影，更自然 |
| 一致性 | 面对不同文本时更可靠 |

可以考虑补充这些样本：

1. **不同语气** — 随意、正式、兴奋、平静
2. **不同内容** — 叙述、提问、陈述
3. **不同录音条件** — 棚录质量、普通房间声学

<Aside type="caution">
所有样本必须来自**同一位说话人**。混用不同人的声音会得到很差的结果。
</Aside>

### 处理已有音频

手上已有现成音频（播客、视频等）时：

<Steps>
  <Step title="挑出干净的人声">
    只保留目标说话人独白的片段，没有背景音乐，噪声尽量少。
  </Step>
  <Step title="用音频编辑器处理">
    Audacity、Adobe Audition 之类的工具：剪出 10–30 秒干净片段，去掉首尾静音，把音量归一化。
  </Step>
  <Step title="导出为 WAV">
    以高质量 WAV 保存。
  </Step>
</Steps>

背景噪声较轻时，可以用 Audacity 的降噪，参数要保守——过度处理会引入新的伪影。

### 测试与迭代

1. **生成测试句** — 先试一句简单的话，例如「你好，这是对我声音配置文件的一次测试。」
2. **评估效果** — 听语气是否自然、吐字是否清楚、韵律是否合理、有没有伪影。
3. **调整** — 质量差就补充样本、换源音频，或检查样本质量。

#### 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 机器人音 | 样本质量差或太短 | 换更长、更高质量的样本 |
| 语气不对 | 样本的情绪与目标不符 | 按你想要输出的风格重新录 |
| 伪影／爆音 | 样本里有背景噪声或音频问题 | 清理样本，或换更安静的环境重录 |

## 工作流 B：预设型配置文件

不想录任何东西、想直接用现成音色时用这条流程。可用引擎：**Kokoro 82M**（50 个音色）与 **Qwen CustomVoice**（9 个音色），完整清单见[预设音色](/docs/guide/preset-voices)。

<Steps>
  <Step title="新建配置文件">
    `Profiles` → `+ New Profile` → 引擎选择 **Kokoro** 或 **Qwen CustomVoice**。
  </Step>
  <Step title="挑一个音色">
    会显示该引擎的音色目录，点任意音色即可试听。
  </Step>
  <Step title="命名并保存">
    给配置文件起个名字。不需要音频样本。
  </Step>
  <Step title="生成">
    配置文件立刻可用，在浮动生成框或 Generate 页面里选它即可。
  </Step>
</Steps>

<Aside type="note">
预设型配置文件**锁定在其来源引擎上**。在浮动生成框里切到别的引擎时该配置会被置灰，因为这个音色只存在于那个引擎里；点击置灰的配置会自动把引擎切回去。
</Aside>

### Qwen CustomVoice 与 instruct

Qwen CustomVoice 的预设音色支持**表达指令**（delivery instructions），用自然语言控制语气、语速和情绪。选中 Qwen CustomVoice 配置文件后，浮动生成框的生成按钮旁会出现一个滑块图标，点开即可展开 instruct 输入框。示例见[预设音色](/docs/guide/preset-voices)。

## 进阶技巧

### 名人／角色声音（克隆）

克隆公众人物或角色时：

1. **法律** — 确认你有权使用，或明确属于合理使用。
2. **素材质量** — 找高质量采访音频或干净的片段。
3. **一致性** — 用他们说话方式接近的片段。
4. **多个样本** — 对有辨识度的声音尤其重要。

### 口音与方言（克隆）

克隆模型会保留口音和方言：英式英语的样本生成英式英语的输出，南方口音的样本生成带南方口音的输出，地区性发音也会被保留。

### 情绪迁移（克隆）

样本的情绪会带到生成结果上：高能量的样本得到高能量的输出，平静的样本得到平静的输出；混合不同情绪的样本能让配置文件更通用。

Qwen CustomVoice 的预设音色则应改用 **instruct** 字段表达风格，而不是依赖样本情绪——instruct 就是用来做这件事的。

## 管理配置文件

### 整理

- **描述性的名字** — 例如「张三 - 专业旁白」
- **写描述** — 记录录音条件、用途，或用的是哪个预设音色
- **语言标记** — 标出主要语言
- **归档不用的** — 让列表保持可读

### 导出与导入

- **导出**配置文件用于分享或备份
- 从同事那里**导入**
- **克隆型**配置导出时带声音嵌入，不带原始音频
- **预设型**配置只导出引擎 + 音色 ID 的元数据，导入方必须装了该引擎的模型
