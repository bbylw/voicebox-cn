Voicebox 把整条语音链路放进一个桌面应用里：一边是语音输出（8 种 TTS 引擎、零样本克隆、声音人格、故事编辑器），另一边是语音输入（全局听写、Whisper 转录、Captures 归档）。两边共用一个极小的系统级悬浮胶囊，你始终知道机器什么时候在听、什么时候在说。

所有推理都在你的机器上完成——Apple Silicon 走 MLX，Windows 和 Linux 走 PyTorch（CUDA / ROCm / DirectX 12 / XPU）。首次下载模型需要联网，之后可以完全离线工作。

## 从这里开始

- [安装 Voicebox](/docs/getting-started/installation) —— 下载安装包，或在 Docker、Linux 源码里跑起来
- [快速开始](/docs/getting-started/quick-start) —— 五分钟内克隆一个声音并生成第一段语音
- [全局听写](/docs/guide/dictation) —— 在任何应用里按住快捷键说话，松手就完成输入
- [MCP 服务器](/docs/guide/mcp-server) —— 让 Claude Code、Cursor 用你克隆的声音说话
