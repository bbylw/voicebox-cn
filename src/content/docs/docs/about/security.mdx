## 数据留在本地

语音生成、克隆、转录都在你的机器上完成。应用不会上传音频、文本或声音配置文件；只有在首次下载模型、检查更新时才会访问网络。

数据目录（各平台路径见[安装](/docs/getting-started/installation)）里有声音配置文件、样本、生成结果与 Captures，备份或清理时直接操作这个目录即可。

## 本机 API 的边界

后端默认只监听 `127.0.0.1:17493`，没有鉴权。任何能访问这个端口的本机进程都可以调用生成接口。不要把它直接暴露到公网；需要远程访问时，用[远程模式](/docs/getting-started/remote-mode)或带鉴权的反向代理。

MCP 客户端通过 `X-Voicebox-Client-Id` 标识自己，这用于选择要用的声音，不是安全边界。

## 克隆的道德与法律

只克隆你有权使用的声音。冒充他人、制作误导性音频在多数司法辖区都可能违法。发布合成语音时，建议明确标注它是 AI 生成的。
