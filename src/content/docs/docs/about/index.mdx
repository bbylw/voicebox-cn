Voicebox 是一个本地优先的开源 AI 语音工作室，由 [Jamie Pine](https://github.com/jamiepine) 发起。它把语音输出（克隆、生成、故事、人格）和语音输入（听写、转录、Captures）放进同一个桌面应用，并且默认不把音频或文本发到任何服务器。

本中文站（`bbylw/voicebox-cn`）是社区维护的简体中文文档与落地页，内容跟随上游 `jamiepine/voicebox` 更新，与上游项目没有隶属关系。发现翻译问题欢迎在[本站仓库](https://github.com/bbylw/voicebox-cn/issues)提 issue。

## 本站的技术栈

落地页与文档站使用 [Astro](https://astro.build/) + [Nimbus](https://nimbus-docs.com/) 构建，依赖安装与构建由 [Bun](https://bun.com) 驱动，部署在 GitHub Pages。文档同时输出 `/llms.txt` 与每页的 Markdown 版本，方便智能体直接读取。
